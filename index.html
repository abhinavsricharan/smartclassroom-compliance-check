Warning 1. Unsalted SHA-256 Password Hashing - DPDP Section 8
src/classpulse/governance.py : Line 58

Diagnostic Message: Passwords hashed using unsalted SHA-256 (hashlib.sha256). Section 8 mandates reasonable security safeguards to protect personal data. 

# Flagged Code (src/classpulse/governance.py:57-58):
def hash_password(password: str) -> str:
    return hashlib.sha256(password.encode("utf-8")).hexdigest()

Statutory Risk Analysis & Technical Remediation

Legal Impact: Section 8(5) of the DPDP Act obligates data fiduciaries to implement reasonable security safeguards to prevent personal data breaches. Unsalted SHA-256 hashes are susceptible to precomputed rainbow table lookups if the CLASSPULSE_USERS environment variable is exposed.

Recommended Engineering Fix: Upgrade to key-stretched, salted PBKDF2 (hashlib.pbkdf2_hmac) or migrate to institutional Microsoft Entra ID (Azure AD) SSO: 

import hashlib, secrets

def hash_password_secure(password: str, salt: bytes | None = None) -> str:
    salt = salt or secrets.token_bytes(16)
    key = hashlib.pbkdf2_hmac('sha256', password.encode('utf-8'), salt, 100_000)
    return f"{salt.hex()}:{key.hex()}"
Advisory 2. Plaintext JSONL Audit Trail - DPDP Section 8
src/classpulse/governance.py : Line 128

Diagnostic Message: Direct plain-text JSONL persistence for audit logs and student identifiers. Ensure student audit trails are protected with at-rest encryption and concurrency safeguards. 

# Flagged Code (src/classpulse/governance.py:127-129):
destination = path or AUDIT_LOG_PATH
with destination.open("a", encoding="utf-8") as handle:
    handle.write(json.dumps(entry) + "\n")

Statutory Risk Analysis & Technical Remediation

Operational Context: While default student data is synthetic (S001...), real deployments must protect audit trails from unauthorized filesystem access. Additionally, plain file appends without POSIX locks (fcntl / portalocker) risk corrupted lines if multiple advisors access the system concurrently.

Recommended Engineering Fix: Transition from flat-file JSONL to Azure Table Storage with Customer-Managed Keys, PostgreSQL with Transparent Data Encryption (TDE), or SQLite in WAL mode.
